# Конструктор учебных сценариев (Unity)

Сценарий собирается в Unity Editor без кода. Одни и те же шаги проходятся в двух режимах — **обучение** и **экзамен**. Действия игрока пишутся в журнал, по журналу считается оценка.

## Как устроено

- **ScenarioManager** — объект на сцене, где настраивается весь сценарий: режим, этапы с тестами, порог нарушений, логгер, анализаторы, экранный интерфейс.
- **Тесты** — префабы из `Assets/TestPrefabs` (Trigger, Collision, Button, UnityEvent, Trigger A → B, Object State), расставленные на сцене. В корне каждого — компонент шага, остальное — оформление.
- **Этапы (Stages)** идут по очереди; тесты одного этапа активны одновременно.
- **ScenarioUI** — задания, сообщения о нарушениях, итог и журнал на экране.

## Как пользоваться

1. Поставить тест-префаб на сцену, заполнить у шага название, описание и подсказку.
2. В ScenarioManager → **Stages** добавить этап и перетащить в него тесты:
   - один этап с несколькими тестами — одновременная активация;
   - несколько этапов по одному тесту — последовательная.
3. **Exam Group** у этапа — номер группы экзамена. **Violation Threshold** — сколько нарушений допускается в группе, по достижении остаток группы пропускается.
4. **Current Mode** — Training или Exam. **Out Of Order Policy** — считать ли действие вне очереди нарушением.
5. Связи событий настраиваются в инспекторе: On Click кнопок пульта, On Switched рубильника.
6. **Logger**, **Training / Exam Analyzer**, **View** — какие компоненты журнала, оценки и вывода использовать.
7. **Play** — прохождение начинается сразу. В конце на экране итог и журнал, они же дублируются в Console.

   Повторная оценка другим анализатором и перезапуск — меню ⋮ у ScenarioManager.
